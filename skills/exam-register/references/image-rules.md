# 이미지 보존과 크롭

확인한 렌더링 이미지 크기와 정수 bbox [x0,y0,x1,y1]를 사용한다. PDF 포인트·축소 화면 좌표를 혼용하지 않는다.
`scripts/crop_image.py <page.png> --bbox 100 200 600 900 --output <작업폴더>/runs/<id>/assets/q1.png`

크롭은 리사이즈 없이 PNG로 저장한다. 잘라낸 뒤 실제 파일과 전체 페이지를 함께 열어 제목·범례·사진·캡션·화살표·표 마지막 행·장식까지 포함되는지 확인한다. 질문·선택지의 불필요한 혼입을 제거한다. 잘못된 경계는 에이전트가 수정하고 다시 자른다.
확대가 필요하면 원본 PDF를 다시 렌더링한다. 작은 이미지를 단순 확대하거나 생성형 이미지로 다시 그려 원본을 대체하지 않는다.
여러 페이지의 자료는 페이지별 이미지 요소와 순서를 유지한다. 원본 비율을 유지하고 naturalWidth/naturalHeight를 업로드 파일과 맞춘다.
asset_upload 뒤 assetId와 URL을 기록하고 이미지 삽입 명령을 별도로 호출한다. 업로드 성공만으로 본문 삽입 성공을 보고하지 않는다. 실패하면 이미지 단계에서 재개하고 텍스트·표로 자동 대체하지 않는다.
