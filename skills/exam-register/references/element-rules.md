# 요소 계획

## 문서 유형과 내부 형식

- 공통 지문은 별도 일반 리치에디터 문서(`general_document`)로, 개별 문항은 `qti_item`으로 등록한다. 사용자가 통합을 명시하지 않았다면 공통 지문을 문항 본문에 복제하지 않는다. 연결 문항과 지문 문서 ID를 기록하며, 같은 폴더에 있다는 사실을 네이티브 공유 연결로 보고하지 않는다.
- 일반 리치에디터는 문서 유형이다. 보기박스는 그 문서 내부의 표현이므로 서로 배타적이지 않다. `text` 표현은 편집 가능한 내용이라는 뜻이지 박스 없는 문단이라는 뜻이 아니다.
- 원본의 박스 밖 안내 머리글(예: `[1~3] 다음 글을 읽고 물음에 답하시오.`), 박스 본문, 박스 자체의 제목을 구별한다. 안내 머리글을 박스 제목으로 옮기지 않는다. 원문에 제목이 없는 지문 박스에는 기본 `<보기>` 제목을 남기지 않는다.
- 원문에 박스가 있으면 일반 문서 안에 보기박스를 만들고 텍스트를 채운다. 원문에 박스가 없으면 임의로 만들지 않는다. `(가)·(나)`의 위치, 문단, 밑줄, 글자 테두리도 보존한다. 인쇄상의 단/페이지 연속을 별개 지문으로 오인하지 않는다.
- 문항 자체의 보기는 그 문항에 유지한다. 공통 지문 분리와 개별 보기 제거를 혼동하지 않는다.

문항 번호·시작/끝·다단 순서·공통 자료를 확인한 뒤 요소마다 semantic_type, representation, reason을 기록한다. 원본에 없는 요소를 생성하지 않는다.

## 문단 들여쓰기와 정렬

- 원본 PDF를 시각적으로 확인하여 각 문단의 첫 줄 들여쓰기 유무·크기와 정렬 방식을 판단한다. 첫 줄 시작 위치를 같은 문단의 나머지 줄과 비교하고, 양쪽 줄 끝과 줄바꿈을 함께 살핀다. PDF 텍스트 추출 결과의 공백이나 모든 줄의 시작 위치만으로 첫 줄 들여쓰기를 단정하지 않는다.
- 첫 줄 1자 들여쓰기와 양끝 정렬은 필수조건이나 기본값이 아니다. 원문에 해당 서식이 확인되거나 사용자가 해당 범위에 명시적으로 요청했을 때만 적용한다. 원본보다 사용자 요청이 우선하는 경우에도 지정된 문항·지문·문단 범위에만 적용하고, 다른 문항이나 모든 보기박스로 확대하지 않는다.
- 본문, 대화, 시, 중략 안내, 작품명·출처는 문단 역할과 배치가 다를 수 있다. 같은 박스 안에 있다는 이유로 동일한 들여쓰기·정렬을 기계적으로 적용하지 않는다. 시의 행갈이, 대화의 문단 구분, 중략 안내와 출처의 개별 배치도 원문 기준으로 유지한다.
- 요소의 판정 이유 또는 별도 서식 계획에 문단 식별 정보, 원본에서 관찰한 들여쓰기·정렬, 적용할 값과 단위, 원본 근거 또는 사용자 요청 범위를 기록한다. 원본의 글자 단위를 MCP의 수치로 옮길 때는 현재 도구 스키마의 단위와 지원 범위를 확인한다. 현재 지원 명령과 단위는 [MCP 등록·복구](teamsword-mcp.md#문단-서식구간-대괄호언어-블록-2026-09-12-배포본-기준)의 표를 따른다. 정렬·들여쓰기를 공백 삽입으로 임의 모사하지 않는다.
- 판단이 불명확하면 확대 원본을 확인하고, 여전히 불명확하면 해당 문단의 미확인 범위를 기록한다. MCP가 원문 서식을 지원하지 않으면 미지원으로 남긴다. 불확실성이나 미지원 때문에 전체 문단을 임의의 서식으로 통일하지 않는다.

## 요소별 표현

| 원본 | 의미 유형 | 표현 |
|---|---|---|
| 질문·선택지 | prompt / choice | 편집 가능한 text, 필요한 부분은 latex |
| 일반 지문·보기 | passage / viewbox | text, 원본 강조·문단 보존 |
| 지도·사진·비문·편지 | map / photo / image | 제목·설명·장식까지 하나의 image |
| 표 모양의 시각 자료·연표 | table / timeline | 원본 배치가 의미를 가지면 image |
| 순수 데이터 표 | table | 사용자가 편집 가능 표를 원하고 원본 재현이 가능하면 native_table |
| 수식·그래프 | formula / graph | 수식 latex, 그래프 image |

박스 유무나 PDF 내부 래스터 여부만으로 결정하지 않는다. 자료 안 텍스트를 편집 가능한 지문으로 임의 분리하지 않는다. 한국사 4번 같은 연표는 table/timeline + image 사례다.
공통 자료를 문항마다 중복 추출하지 않는다. TeamsWord의 공유 연결이 실제 지원되지 않으면 미지원으로 기록하고 별도 지문 문서를 유지한다. 사본 삽입은 사용자가 요청한 경우에만 수행한다.
수식, 지수 부호, 한자·옛한글, 밑줄·사각 테두리는 확대 대조한다. 모르는 글자는 추측하지 말고 issues에 남긴다.
